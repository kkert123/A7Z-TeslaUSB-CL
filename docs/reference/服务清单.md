# 服务清单

> `services/` 下所有 systemd 单元。装机时全部复制到 `/etc/systemd/system/` 后 `daemon-reload`。

---

## 常驻服务

| 单元 | 用途 | 重启影响 |
|------|------|----------|
| `teslausb-web.service` | Flask Web 服务，监听 5000 | 短暂无法访问，不影响车机写入 |
| `teslausb-sentry.service` | 哨兵事件检测主进程 | 期间的事件会漏检 |
| `teslausb-gadget.service` | USB Gadget 守护进程（UDC 绑定） | **车机会短暂断开** |
| `teslausb-watchdog.service` | 硬件看门狗 | 失去死机自恢复能力 |
| `teslausb-mode.service` | 开机决定 Present / Edit 模式 | — |
| `teslausb-boot-notify.service` | 开机企业微信通知 | 漏一次开机通知 |
| `teslausb-io-tune.service` | I/O 性能调优 | 性能回落 |
| `teslausb-fan.service` | 风扇控制 | 温度升高 |
| `teslausb-sync.service` | NAS 同步 | — |
| `teslausb-notify-retry.service` | 推送失败补发 | 补发失效 |

## 定时任务

| 单元 | 周期 | 用途 |
|------|------|------|
| `teslausb-fsck.timer` | 每周 | exFAT 文件系统检查 |
| `teslausb-remount.timer` | 周期 | 分区重新挂载 |
| `teslausb-logrotate.timer` | 每日 | 日志轮转 |
| `teslausb-sync.timer` | 周期 | 触发 NAS 同步 |
| `teslausb-notify-retry.timer` | 周期 | 触发推送补发 |
| `wifi-quick-check.timer` | 短周期 | WiFi 快速连通性检查 |
| `wifi-full-check.timer` | 长周期 | WiFi 完整检测与最优切换 |

## 最小可用集

只跑核心功能时需要这三个：

```bash
sudo systemctl enable --now teslausb-web teslausb-sentry teslausb-gadget
```

---

## 常用命令

```bash
# 状态一览
systemctl list-units 'teslausb-*' 'wifi-*' --all

# 单个服务
systemctl status teslausb-web
systemctl is-active teslausb-web        # 只返回 active/inactive，脚本用

# 日志
journalctl -u teslausb-web -f            # 实时跟踪
journalctl -u teslausb-web -n 100 --no-pager
journalctl -u teslausb-sentry --since "1 hour ago"

# 重启（Web 服务建议用完整三步，见日常部署与回滚）
sudo systemctl restart teslausb-web
```

## 日志文件

| 路径 | 内容 |
|------|------|
| `/var/log/teslausb.log` | Web 服务 |
| `/var/log/teslausb-sentry.log` | 哨兵检测 |
| `/var/log/teslausb-gadgetd.log` | Gadget 守护 |
| `/var/log/wifi-smart-switch.log` | WiFi 智能切换 |

## 注意事项

**timer 是无主资产。** systemd timer 不会随代码更新自动分发，必须：

1. 加进 `deploy_manager.py` 的 `MANAGED_FILES` 白名单
2. 在常驻服务里加幂等自愈逻辑（如 `ensure_smart_switch_timers`）

否则一次清理或换机，timer 就再也不回来了（[M45](../reference/教训索引.md)）。

**dnsmasq 与 systemd-resolved 争 53 端口。** AP 场景下 dnsmasq 配 `port=0`（纯 DHCP，不做 DNS）；关闭 AP 时要删掉 `/etc/dnsmasq.d/ap.conf`（[M46](../reference/教训索引.md)）。
