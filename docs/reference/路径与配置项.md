# 路径与配置项

> **所有路径常量以 `config.py` 为准。** 改路径先改 `config.py`，其他模块一律从它导入。
> 各模块自己硬编码路径是历史上多次事故的根源（[M19](../reference/教训索引.md)）。

---

## 目录布局

```
/opt/radxa_data/              DATA_ROOT
├── teslausb/                 TESLAUSB_ROOT —— 代码与配置
│   ├── config/               CONFIG_DIR
│   │   ├── sentry.json       企业微信 Webhook + 哨兵配置
│   │   ├── config.json       应用级配置
│   │   └── rclone/rclone.conf
│   ├── data/                 DATA_DIR
│   │   └── push_health.json  推送健康记录
│   ├── static/
│   │   └── thumbnails/       缩略图
│   ├── services/             systemd 单元
│   └── udev/                 99-usb-gadget.rules
├── data/
│   └── sentry_events.json    哨兵事件状态（注意：不在 teslausb/ 下）
└── venv/                     Python 虚拟环境

/mnt/teslacam/                车机分区（Present 模式只读挂载）
└── TeslaCam/
    ├── RecentClips/          车机循环写入，文件名会被回收
    ├── SentryClips/
    └── SavedClips/

/mnt/music  /mnt/boombox  /mnt/lightshow    媒体分区

/var/log/teslausb*.log        日志
```

### 容易写错的路径

| 用途 | 正确路径 | 常见错误 |
|------|----------|----------|
| 哨兵状态 | `/opt/radxa_data/data/sentry_events.json` | 写成 `teslausb/data/` 下 |
| 推送健康 | `/opt/radxa_data/teslausb/data/push_health.json` | 写成 `config/sentry.json` |
| 缩略图前缀 | `SEN_` / `SAV_` / `REC_`（短名） | 写成 `SentryClips_` 全名（[M20](../reference/教训索引.md)） |

## 配置文件

### `config/sentry.json`

企业微信 Webhook、哨兵开关、推送策略。**不进 git，不进升级包**，换机需单独迁移。

### `config/config.json`

应用级设置。同样不进包，升级时由 `_restore_user_data` 从备份恢复。

> v0.3.1.4 之前升级包里带过真实凭据（Webhook key、密码 hash）。这些 Release 已全部删除，密钥也已轮换。现在 `config/` 目录整体不进包。

### `config/rclone/rclone.conf`

rclone 远程配置，支持 14 家云盘。

> NAS 类服务商不走 OAuth，判断 `remote_configured` 时**不能**依赖 `auth_info["authorized"]`。

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `WECOM_DATA_DIR` | `DATA_DIR` | 覆盖 `weixin_notifier.py` 的硬编码路径，由 `config.py` 通过 `setdefault` 设置 |

---

## 关键常量

| 常量 | 值 | 位置 | 说明 |
|------|-----|------|------|
| `APP_VERSION` | 递增 | `config.py` | 唯一版本来源 |
| `ENSURE_TTL_SEC` | 30 | `utils/cache_coherency.py` | 缓存刷新节流窗口 |
| `WRITE_STABLE_SEC` | 60 | 同上 | 车机停写入判定窗口 |
| `S3_FORCE_TTL_SEC` | 120 | 同上 | 指纹失效时的强制刷新兜底 |
| `TESLA_SSID_PREFIX` | `Tesla` | `config.py` | 车机 WiFi SSID 前缀，用于门控启动 |
