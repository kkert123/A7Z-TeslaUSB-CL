# 版本历史

> v0.3.1.20 起的变更索引。完整发布说明见 [GitHub Releases](https://github.com/kkert123/A7Z-TeslaUSB-CL/releases)。
> v0.3.1.19 及更早的历史在 `_all_bodies.txt` 里。

版本格式 `0.3.1.<N>`，来源 `config.py: APP_VERSION`。

---

## v0.3.1.40 · 2026-09-03

- `ensure_fresh` 双语义：前台读取（列表/播放/缩略图）检测到车机写入立即刷新，后台兜底走 A1 延迟刷新。修复 v0.3.1.39 把前台一并延迟导致的缓存冻结回归
- RecentClips 页面加手动刷新按钮
- udev 规则随包发布（`upgrade_service` post-install 钩子自动部署到 `/etc/udev/rules.d/`）

## v0.3.1.41 · 2026-09-03

- 后台缩略图自动生成回归修复：撤销 v0.3.1.40 对 bg_preview 强制传入的 `background=True`（A1 延迟刷 + 无人访问时 readdir page cache 冻结 → 后台零生成，实证 2.5h）
- `/recent-clips` 页面 + `/api/camera/recent-thumbnails` 前置前台 `ensure_fresh`（补 v0.3.1.31 读取驱动缺口，页面打开最坏 ~120s 有界解锁）
- `_coherency_loop` 保持 A1 延迟刷（UI_a112 主防护不动）
- 教训：M58（readdir 感知概率性，M52 修正）、M59（交叉审查单目标优化需先验核心功能）

## v0.3.1.39 · 2026-08-31

- 缓存刷新改为延迟触发（A1）：车机在写时只标记，停手 60 秒后才回收。修复车机 UI_a112「USB 设备故障」
- AP 让出探测改为轮询等待扫描结果（每 3 秒、最长 30 秒）。修复手机配完网后不切回 WiFi
- `99-usb-gadget.rules`：bind 分支加 UDC 未激活守卫，删除 unbind 分支的 xhci-hcd 操作（需手动部署）
