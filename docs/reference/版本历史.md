## v0.3.1.62 · 2026-10-05（**已发布** Release ID 403495029 / tag→`385aa7b`）

- **现象（用户请求）**：把「AP↔STA 互斥切换」改为 **AP+STA 并发**——**热点与 WiFi 同时工作**，WiFi 恢复后热点按策略自动处理；并在页面加并发开关。这是彻底消除「AP 开了就回不去 WiFi」结构缺陷的改造（此前 v59/v60 的 M89/M90 都是为互斥打的补丁）。
- **M1 骨架**（`config.py` + `wifi_service.py`）：新增开关 `AP_STA_CONCURRENT_DEFAULT=False`（灰度）；`AP_VIF` 常量与独立实例封装（`_use_concurrent` / `_ap_vif_add·del` / `_sta_link_freq`·`_sta_current_channel` / 独立 hostapd·dnsmasq 起停 / `_ap_concurrent_iptables`）；**legacy 路径零改动**。
- **M2 并发起停**：新增 `_ap_bring_up_concurrent` / `_ap_bring_down_concurrent`；`_ap_bring_up`/`_ap_bring_down`/`_write_hostapd_conf`/`_ap_is_running`/`_ap_has_clients`/`_ap_ensure_down`/`_ap_self_heal` 加并发分支（**方案 B**）；`system_monitor.py` 的 AP 提醒判据改 `_ap_is_running`（兼容独立实例）。并发起 AP **不释放 wlan0**（wlan0 恒作 STA），起停对 STA 零扰动。
- **方案 B（关闭策略）**：STA 恢复后——**无客户端 → 立即关 ap0**；**有客户端 → 不关、不踢**，等其断开再关；客户端连超 30min 推提醒（不踢）。复用既有 `has_clients`/`client_just_left`/`_note_ap_client_stuck`，并新增 `_ap_started_manually()` 使**手动开的 AP 不被自愈自动关**。
- **M3 信道跟随**：`_sync_ap_channel`（CSA 优先 `hostapd_cli chan_switch`、重启兜底）+ `_channel_to_freq`/`_ap_vif_current_channel`；接入 `quick_check`（每 2min）；**STA 未关联则跳过**（防误跟默认 ch6）+ transition 护栏。
- **M4 UI + 事件回调**：`templates/wifi.html`「AP 配置」加**「AP 与 WiFi 并发」复选框**；`set_ap_config` 加 `ap_sta_concurrent` 参数、路由 GET 返回生效值 / POST 透传；`ap_client_event.sh` **ifname 化**（读 `/tmp/a7z_ap/ifname`）+ 新增 `_ap_start_client_monitor_vif`（独立实例监听）+ `_ap_bring_up/down_concurrent` 写/清 ifname 文件 + `_yield_ap` 并发分支（手动 AP / STA 未恢复 / 仍有客户端 均不关）。
- **M94 远程自锁闸**：新增 `_remote_lock_risk()`——legacy 路径 + wlan0 为**唯一默认路由**时判风险；`start_ap(force=False)` 前置拒绝（不改动任何状态），路由透传 `force`。防「远程手动开 AP → 释放 wlan0 → 自断链路」（10-04 事故）。
- **M95 开机通知后台化**：`app.py` 把 `app.run()` 之前的**同步**开机通知抽成 `_send_boot_notification()` 以 daemon 线程发送 → **断网时 Web 立即监听 5000**（此前 `send_text` 失败重试最长阻塞 ~3.5min，导致 AP fallback 模式下 Web 打不开）。
- **真机暴露并修（教训 M96）**：`quick_check`「网络正常」分支的**无条件 `_ap_ensure_down()`**，在并发下（wlan0 恒 STA → 网络恒"正常"）**每 2min 无条件关 AP**（含手动开的）。修复：该分支加 `and not _use_concurrent()` 守卫，并发交由 `_ap_self_heal`（方案 B）。
